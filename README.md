# Treino da Maria Clara

PWA mobile-first para acompanhar a rotina de treino, registrar carga/repetições, marcar exercícios concluídos, consultar exemplos de execução e usar cronômetro de descanso.

Os dados do treino são salvos no `localStorage` do aparelho.

## Extras

- Enfeites com Kuromi treinando em pontos do app.
- Exemplos de exercício por modal com link para vídeo.
- Cronômetro de descanso 60/90/120 s.
